# Kappa Text Future Redesign Backlog

Status: deferred

Current rule:
- do not change the visual behavior of `Kappa Text` during source-cleanup work
- treat the current KM source state as the approved Readerly-faithful baseline

Design direction:
- explicit goal: make `Kappa Text` as close as reasonably possible to Bookerly in reading feel and overall texture
- hard constraint: the work must remain non-infringing and legally clean
- implementation rule: similarity must come from original KM design decisions, not direct copying of protected source material
- current watchlist scope: effectively the entire family, since the long-term direction is broadly "more Bookerly, less Readerly"

Current references:
- Readerly-faithful approved baseline: `proofs/kappa-text.html`
- Bookerly sample reference: `references/kappa-text/bookerly`

Deferred future work:
- compare reading texture against Bookerly deliberately, not implicitly
- identify specific targets before changing outlines or metrics
- focus on visual outcomes such as size, darkness, spacing texture, rhythm, and page color rather than copying source data
- make only intentional visual changes with proof review after each step

Suggested workflow when the time comes:
1. snapshot the approved Readerly-faithful baseline
2. define one narrow design target at a time in relation to Bookerly-like reading behavior
3. rebuild and regenerate proofs after each step
4. compare against both the frozen baseline and the Bookerly reference
5. accept only changes that are visually intentional and legally clean

Current non-goals:
- no spacing redesign yet
- no feature behavior redesign yet
- no outline redesign yet
