# Kappa Type Licensing Notice

Kappa Type uses a split license model.

## Font Software

The font families, font binaries, UFO/designspace/font source files,
font metadata, and webfont files are licensed under the SIL Open Font
License, Version 1.1.

This applies to:
- `fonts/`
- `sources/`
- `licenses/`

The upstream copyright notices, OFL files, and provenance notes for
each family are preserved under `licenses/<family>/`.

Modified fonts are distributed under KM family names only:
- Kappa Text
- Kappa Mark
- Kappa Form
- Kappa Mono
- Kappa Spin
- Kappa Hand, when it exists

They must not be distributed under upstream family names such as
Readerly, ABeeZee, Open Sans, Commit Mono, or Comfortaa.

## Repository Software

Repository tooling, build scripts, proof scripts, validation scripts,
generated CSS font-face helpers, project documentation, and non-font
automation are licensed under the Apache License, Version 2.0.

This applies to:
- `scripts/`
- `families/`
- `proofs/`
- top-level project documentation
- repository configuration files

The Apache License text is available in `LICENSE-APACHE`.

## Upstream Notices

The files in `licenses/<family>/` are copied from their respective
upstream projects and remain governed by their original notices.

This notice is intended to clarify license scope. It does not replace
or weaken the upstream notices that must be preserved with the fonts.
